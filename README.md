# Focus Flow

Build a brand-new mobile-first web app called “AI Productivity Assistant”.

The app solves a common problem: people struggle to organise their daily tasks, decide what is important, and manage their time effectively.

Target users: students, job seekers, employees, entrepreneurs, and anyone who needs help organising their daily activities.

Create a modern, professional, simple and responsive interface that works especially well on mobile phones.

Main features

Dashboard — Show today's tasks, completed tasks, pending tasks, and a simple productivity overview.

Add Task — Allow users to create a task with a title, description, priority (High, Medium, Low), and due date.

Task Management — Users can view, complete, edit, and delete tasks.

Priority System — Clearly identify high-priority tasks so users know what to focus on first.

Daily Productivity — Show users their progress throughout the day.

Simple AI Assistant area — Create an assistant section where users can ask for help organising their tasks and planning their day. If real AI integration is not available, create the interface and demonstrate the intended functionality without pretending that a live AI service is connected.

Clean navigation — Include Dashboard, Tasks, Assistant, and Profile/Settings.

Design

 Modern professional appearance

 Mobile-first responsive design

 Clean dashboard

 Easy-to-read typography

 Attractive cards and buttons

 Clear task priority indicators

 Smooth user experience

 Professional enough to demonstrate to potential investors

 Do not use a personal photo

Important

Make the application functional, not just a static design. Users should be able to add tasks, mark tasks as completed, edit tasks, delete tasks, and see their productivity progress.

Build the complete first version of the application now.
